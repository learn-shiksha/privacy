Privacy Policy

FinAI Pipeline · Last updated: October 25, 2026

About this application

FinAI Pipeline is a personal tool used only by its owner to manage the owner's own YouTube channel. It is not offered to the public and has no other users.

Information accessed

With the owner's permission, the application uses the YouTube Data API to upload videos and to set titles, descriptions, tags and thumbnails on the owner's own channel. It does not access the data of any other Google user.

How information is used and stored

Login credentials (an access token) are stored only on the owner's own computer. They are used solely to perform the actions described above. The application does not collect, sell, share or transfer personal data to any third party, and it does not use data for advertising.

Google API Services

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data deletion and revoking access

The owner can revoke the application's access at any time at myaccount.google.com/permissions and can delete the locally stored token file.
